<h3>Навыки и направления работы</h3>

<ul>
  <li><strong>Тестирование API:</strong> Проверка REST и SOAP сервисов, валидация статус-кодов, тел ответов и JSON-схем, автоматизация проверок в Postman и SoapUI.</li>
  <li><strong>Анализ сетевого трафика:</strong> Перехват и подмена запросов/ответов через Charles Proxy и Fiddler (Rewrite, Map Local, Breakpoints).</li>
  <li><strong>Базы данных:</strong> Написание SQL-запросов (JOIN, агрегация данных, вложенные запросы) в  MySQL для проверки корректности данных.</li>
  <li><strong>Web и Mobile:</strong> Работа с Chrome DevTools, эмуляция мобильных устройств и сбор логов в Android Studio.</li>
  <li><strong>Тестовая документация:</strong> Составление чек-листов, тест-кейсов и баг-репортов, ведение задач в Jira и YouTrack.</li>
</ul>
